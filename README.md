# Seamless AI Bridge

Seamless AI Bridge is an extensible VS Code chat participant designed to route prompts to custom, self-hosted, and third-party AI models.

## Usage

1. Open VS Code Chat.
2. Mention `@bridge`.
3. Enter your prompt.

Example:

```text
@bridge explain this function and suggest tests
```
